# Demerzel

Demerzel — локальный оркестратор проектов (macOS). MCP-сервер `demerzel` в `mcp/demerzel-mcp.mjs` подключён через `.mcp.json`.

## Инструменты

- `list_projects` — найти проекты в `DEMERZEL_ROOTS` (или переданных `roots`).
- `project_config` — прочитать `orchestrator.json` проекта.
- `discover_automations` — скрипты `package.json` как кандидаты автозадач (только чтение). `likely_automation` — подсказка по имени, решает пользователь.
- `set_automation_selection` — записать выбранные автозадачи в `orchestrator.json` → `automation.selected`. Остальные поля не меняются.
- `project_status`, `pulse` — статус и прогресс через CLI `dem`.
- `start_project`, `stop_project` — `dem up` / `dem down`.
- `restart_service` — перезапуск одного сервиса (`dem restart`).

## Порядок работы

1. Если путь неизвестен — `list_projects`, и спросить пользователя, какой проект.
2. Перед изменением настроек — `project_config`, чтобы не затереть существующие поля.
3. Автозадачи: сначала `discover_automations`, показать список и подсказки, затем записать только то, что пользователь подтвердил. Не выбирать автозадачи самому без подтверждения.
4. Запуск, остановка и перезапуск — только по прямой просьбе пользователя.

## Ограничения

- Логи и алерты через MCP пока не доступны: CLI их не отдаёт. Для логов — открыть проект в приложении Demerzel.
- Нужен CLI `dem` в PATH (или `DEM_BIN`). Без него запуск/статус вернут понятную ошибку.
- Автозадачи, запущенные из приложения, видны только в приложении.
