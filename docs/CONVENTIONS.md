# Конвенции проекта Demerzel

## Инструменты

- Пакеты и скрипты: Bun (`bun install`, `bun run …`). pnpm и npm не используем, lockfile только `bun.lock`.
- Rust: stable, `cargo`.

## Ветки и PR

- `main` защищена от прямых пушей, работа идёт через PR.
- Имя ветки: `<тип>/<короткое-описание>`, например `feat/ports-table`, `fix/process-kill`, `docs/readme`.
- Одна задача из issues = одна ветка = один PR, где возможно.
- Параллельная работа: каждый issue имеет метки фазы и области (`backend`, `frontend`, `ports`, `agents` и т. д.). Задачи с разными областями можно вести параллельно, задачи одной области с одинаковой фазой лучше делать последовательно.

## Коммиты

Формат Conventional Commits: `тип(область): описание`.

Типы: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `ci`, `perf`.

Пример: `feat(ports): range allocation from project config`.

## Версии

Используется SemVer, версия хранится в файле `VERSION`.

- **Каждый коммит и каждый смердженный PR повышает версию.**
- `fix`, `docs`, `chore`, `refactor`, `test` → патч (`0.0.1` → `0.0.2`).
- `feat` → минор (`0.1.x` → `0.2.0`).
- Ломающие изменения → мажор (после `1.0.0`). До `1.0.0` ломающие изменения повышают минор.
- Версия повышается в том же PR, что и изменение. Не отдельным коммитом после слияния.

## Ветки: после push

После каждого push выполняем `git fetch origin +refs/heads/<ветка>:refs/remotes/origin/<ветка>`, чтобы удалённая ветка была видна локально.

## Журналы

Для каждой версии обновляются два файла.

1. **`CHANGELOG.md`**: технический журнал. Что изменилось, для разработчика, с номером PR.
2. **`MARKETING.md`**: маркетинговый журнал. Короткие формулировки для постов в соцсетях, без технических деталей, с акцентом на пользу.

Формат записи в `MARKETING.md`:

```
## 0.2.0 — 2026-11-03
- Исправлено: ...
- Новое: ...
- Почему это важно: одна фраза.
```

Тон: коротко, по делу, без преувеличений. Не публиковать до того, как функция работает на реальном устройстве.

## Документация

Документация правится в том же PR, что и код. Если поведение, формат или структура изменились, обновляются `README.md`, `docs/` и соответствующие ADR.
